# Turbo Motors

Sitio de servicios de mecánica de motos (aceite, frenos, motor, suspensión, eléctrico y mantenimiento).

## Estado actual

Prototipo frontend con datos de ejemplo (sin backend), pensado para mostrarse rápido en Vercel. Los servicios están en `src/data/services.js` — reemplazar por una API real más adelante no requiere tocar las páginas.

**Pendiente:** la dirección en `src/config/shopInfo.js` es un placeholder ("Dirección por confirmar") — actualizar cuando la tengan.

## Correr en local

```bash
npm install
npm run dev
```

Abre `http://localhost:5173`.

## Desplegar en Vercel

```bash
vercel deploy --prod
```
